# Plyleaf

A free, browser-only PDF toolkit. These are the words we use for what the user works with and how tools connect.

## Language

**Tool**:
One PDF task with its own page, such as Merge, Compress or Sign.
_Avoid_: Feature, app, utility

**Working document**:
The PDF the user is currently carrying from tool to tool on this device, without downloading it in between.
_Avoid_: Session, current file, project

**Step**:
One tool applied to the working document, producing its next version.
_Avoid_: Action, operation, task

**Workbench**:
The place where the working document lives between tools: it shows the document, its steps, the tools to apply next and the download.
_Avoid_: Hub, dashboard, studio

**Saved workflow**:
A named sequence of steps the user keeps and replays on other files. Not the same as the steps of one working document.
_Avoid_: Recipe, macro, chain
