## ui-sdk

Before using ui-sdk (`@ui-sdk/react`, `@ui-sdk/core`):

- Follow the `ui-sdk` skill if it's installed.
- Read `node_modules/@ui-sdk/react/docs/llms.txt`.
- To build a new component, also search `node_modules/@ui-sdk/react/docs/core.md` by heading, and read
  `node_modules/@ui-sdk/react/docs/rendering.md` next to it.
